📄 Digital Library Management System (DLMS) - Project Documentation

1. Project Overview

The Digital Library Management System (DLMS) is a web-based application designed to facilitate the management and distribution of digital books. It provides a platform for members to access and download e-books, staff to manage book uploads, and administrators to oversee the system's operations.

2. Goals

Provide easy access to digital content for authenticated members.

Implement role-based workflows and dashboards.

Track usage and downloads effectively.

Ensure a secure and professional-grade authentication model.

3. Technology Stack


Layer	Technology
Frontend	React.js
Backend	Spring Boot (Java)
Database	MySQL
Email Service	JavaMail with Gmail SMTP
Authentication	Custom logic with optional Spring Security
Data Exchange	RESTful APIs (JSON)
4. User Roles & Functions

Member: Sign up, log in, browse and download books.

Staff: Submit join requests, upload and manage books upon approval.

Admin: Approve staff requests, manage staff, and monitor system usage.

5. Authentication Logic

Member: Signs up with an email, receives a 6-digit PIN via email, and logs in using the email and PIN.

Staff: Submits a join request, awaits admin approval, receives a PIN upon approval, and logs in.

Admin: Logs in with predefined credentials to manage the system.

6. Book Management

Upload: Staff can upload books with details like title, author, description, genre, ISBN, publisher, cover image, and PDF.

Download: Members can download books, and each download is logged with relevant details.

7. Email Integration

Configured via spring.mail.* in application.properties, the system uses JavaMailSender to send:

Member PINs upon signup.

Staff PINs upon admin approval.

8. Notifications

The frontend utilizes notification libraries (e.g., react-toastify) to inform users about:

Login and logout events.

Book downloads and uploads.

Request submissions and approvals.
